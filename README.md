# Fairpay

Zero-friction shared money for any group. Track spends, settle on WhatsApp with country-aware pay links, earn into a group pot.

## Stack

- Expo SDK 58 · Expo Router · React Native
- Zustand + AsyncStorage
- Moti / Reanimated

## Run

```bash
npm install
npx expo start
```
