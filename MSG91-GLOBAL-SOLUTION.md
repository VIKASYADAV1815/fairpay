## 🚀 How to Setup MSG91 (Production)

### Step 1: Create MSG91 Account (5 min)

1. Go to: **https://msg91.com/signup**
2. Select plan:
   - **Free Trial**: 100 credits (~666 SMS) - Test for free! ✅
   - **Starter**: ₹1000 → 6,600 SMS (enough for 3,300 users)
   - **Growth**: ₹5000 → 35,000 SMS (enough for 17,500 users)
3. Complete business verification (takes 24-48 hours)

### Step 2: Get API Credentials (2 min)

1. **Go to:** Dashboard → API
2. **Copy Auth Key** (looks like: `ABC123XYZ456DEF789`)
3. **Copy Sender ID**:
   - India: Use `TXTLCL` for testing, register your brand for production
   - Global: Use `MSGIND` or register your brand

### Step 3: Configure in Supabase (3 min)

1. **Open:** https://supabase.com/dashboard
2. **Select your project**
3. **Go to:** Authentication → Providers
4. **Enable Phone** (toggle ON)
5. **SMS Provider Settings:**
   ```
   Provider: Messagebird (or Custom)
   Auth Key: [Paste your MSG91 Auth Key]
   Sender ID: [Your Sender ID - e.g., TXTLCL]
   ```
6. **Click Save** ✅

### Step 4: Test (5 min)

1. **Open FairPay app**
2. **Phone login screen**
3. **Enter YOUR phone number** (with country code)
4. **Tap "Send OTP"**
5. **Check SMS** (should arrive in 5-10 seconds)
6. **Enter OTP** → Success! ✅
